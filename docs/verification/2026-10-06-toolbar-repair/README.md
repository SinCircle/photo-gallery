# 加载动画、局部阴影与性能修复

本文保留第一次修复的验证记录。回退到此版本后，加载动画另作调整，最新结果见[从左进入、依次推动、向右退出](../2026-10-06-loading-push/README.md)。

本地生产构建预览：<http://127.0.0.1:5187>。基线为本次修改前的 `dc831cf` 构建，另存后从 5189 端口提供；两者使用同一照片库。未部署线上。

## 改动与视觉验证

- 加载时直接显示 56×32 胶囊，避免先展示完整工具条再收缩。三点采用 2.4 秒横向循环、0.8 秒相位错开、加速/减速和 1px 尾部回弹；循环首尾透明度为零。仅动画 transform/opacity，不驱动玻璃重绘。
- 删除 SVG 黑白双描边。保留随照片变化的文字颜色，只对低对比度的局部区域叠加反色柔和阴影。阴影用每约 6px 的空间蒙版控制，明暗方向和强度平滑变化，字形填充独立绘制。
- 消除重复悬停引发的 settle、配置重写、480ms 轮询和未变文字节点替换；去掉逐帧 PNG 编码，将对比度检查合并为一次像素扫描。
- 单面板玻璃不再生成只供后续玻璃折射使用的 DOM 快照。补丁仍保留多面板的原始捕获路径，随 build/dev 自动应用，并校验替换位置。
- 在第一次绘制前明确采样画布的读回用途，消除交互中途的 GPU/CPU 缓冲切换。
- 取消加载状态监听器时正确释放资源；CSS 回退模式也随照片移动更新阴影。窄屏取消 65vw 宽度上限，保证下载按钮不被工具条裁切。

`node scripts/verify-toolbar-repair.mjs` 通过：真实图片请求暂缓下检查加载周期 121 个相位；可见点不重叠、相位速度不同、尾部回弹、透明循环接缝；减少动态效果时保留三个静止点。加载点运行期间，额外墨色采样与玻璃绘制均为零。

三张实拍图片的阴影开关截图有实际像素差异，其中复杂明暗背景同时出现加亮和压暗的阴影。检查无描边节点、无 SVG 描边滤镜、无墨色 PNG 纹理。另验证悬停不打断展开、320/390px 操作按钮处于工具条可见范围内、元数据可滚动、WebGL 禁用后的实时更新、返回画廊无残留场景画布、管理登录页可用。浏览器异常为空。

## 性能对照

Chrome 154，ANGLE / AMD Radeon 硬件加速，1440×1000，DPR 1。两轮交错顺序、每次新文档，每种输入发送 120 次真实 CDP 事件，目标间隔 16.67ms；原版过载时执行时间会延长。帧率来自实际 rAF 时间差，不代表所有设备的帧率。基准期间没有并行运行其他浏览器测试。最后增加的窄屏 CSS 仅作用于 ≤560px，不影响该桌面对照。

| 场景 | 修复前 FPS | 修复后 FPS | 修复前 P95 帧间隔 | 修复后 P95 帧间隔 |
|---|---:|---:|---:|---:|
| 工具条悬停移动 | 70–75 | 239 | 42–50ms | 4.3ms |
| 拖动照片 | 64–65 | 218–227 | 33.4–33.5ms | 8.2–8.3ms |
| 滚轮缩放 | 24–25 | 113 | 125–134ms | 12.6–12.7ms |

修复后两轮所有测试场景的主线程长任务（≥50ms）均为零。静止、悬停时墨色采样、PNG 编码和玻璃 shader 绘制均为零；照片交互时仍正常更新玻璃。图库本身和整页初始化不包含在上述交互性能统计内。

运行：`npm run build`、`node scripts/verify-toolbar-repair.mjs`、`node scripts/benchmark-toolbar-repair.mjs`。验证服务可通过 `VERIFY_DIST`、`VERIFY_PORT`、`VERIFY_UPSTREAM` 指定构建和本机媒体服务。性能脚本支持 `BENCH_URLS` 和 `BENCH_REPETITIONS`。

历史要求等间距/同速度圆点及描边的专项脚本没有改写；本次新脚本验证用户更新后的错峰运动和柔和阴影要求。
