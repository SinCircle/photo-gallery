## 已实施的优化

- **一次读取与一次遍历。** 展开工具栏在手机上原先每轮读取画布 5 次，现在合并为 1 次；仍按原生像素及分数边界做面积积分。平均亮度与列极值共用遍历，利用亮度到对比度的单调性，在空间单元极值上求白/黑最差对比度。没有降低采样分辨率。
- **减少样式计算。** 先集中读取动画状态，再写样式；从 Web Animations 的计算进度恢复中断渐变；复杂遮罩仅放在实际阴影元素上。玻璃和阴影动画参数只传递给需要它们的元素。
- **字体与入口代码。** 将原有四种西文字体的 WOFF2 子集固定到本站，保留字体、字重和 OFL 许可证；内容哈希文件使用长期缓存。管理页 JS/CSS 在进入管理路由时加载，导航取消后不会覆盖新页面。
- **索引与请求缓存。** 复用 `Intl.Collator`，避免每次比较重复建立排序配置。公开接口按文件 inode、大小、纳秒修改/变更时间复用排序后的 JSON，每次请求仍检查文件。浏览器通过 ETag 重新验证，更新、损坏、删除和重建均不会被旧缓存掩盖。
- **后台与发布。** 完成后台控件组装后再测量工具栏，修复上传栏遮挡退出按钮。将镜像版本标签移到依赖安装之后，避免每次发布 Git SHA 都使基础依赖层失效；生产服务器已清理 405.8 MB 可重建构建缓存和一个旧图库镜像，保留当前线上镜像用于回滚。

## 边界与剩余开销

这不是华为手机实机或 HarmonyOS 浏览器的性能数据。DPR 3、4 倍 CPU 降速、工具栏持续展开且图片在其后运动，是刻意保留完整效果的压力场景；仍有明显样式计算和长任务，不能宣称已达到稳定 60 FPS。玻璃、阴影和动画未通过关闭或降低画质来获取这些结果。

并非每项采样都下降：桌面退出阶段累计 CPU 为 125.6→164.6 ms，实际阶段时长约 793→790 ms、长任务仍为 0；手机退出阶段 CPU 基本不变。两轮样本不足以对这些小阶段作统计显著性判断，也不据此声称退出操作加速。

服务器在扫描开始时根分区仅余约 655 MB；清理后预构建完成时仍仅余约 902 MB。图库增长会继续消耗容量，需要后续扩容或单独审查可清理的数据。当前容器空闲采样约 60 MiB / 512 MiB、CPU 0.02%，未发现持续空闲高负载。

$env:PERF_REPEATS='2'
$env:PERF_NAME='performance-20261007-release-abba'
