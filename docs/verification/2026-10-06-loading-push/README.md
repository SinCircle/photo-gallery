# 加载动画：从左进入，依次推动，向右退出

按确认后的动作关系替换上一版往返动画。三个位点仍为 `(14,16)`、`(28,16)`、`(42,16)`；新球从左侧由小变大进入，原有球依次移动一格，最后一球从右侧缩小退出。每轮 1 秒，推动逐球延后 70ms。交接期间最多四个球，停稳时为三个。

![实际页面动画，放大四倍](loading.gif)

位移使用从静止开始的欠阻尼弹簧响应，落位越过约 1px 后回弹。进入/退出具有相同的位移响应以及互补的缩放曲线，缩放在 150ms 内完成。四个节点循环轮换；节点只在完全缩为零后返回左侧。关键帧在模块初始化时计算一次，位移与缩放共用时钟，播放期间无需逐帧脚本或节点增删。

验证已通过：

- `npm run build`。
- `node scripts/verify-loading-spring.mjs`：1440px/DPR 1、390px/DPR 2、320px/DPR 2 各检查 101 个相位。三个原有球开始明显移动的时刻为 80/150/220ms，进入/退出对称、落位回弹、静止位置和循环画面均符合预期，无相交或纵向错位。
- `node scripts/verify-toolbar-repair.mjs`：覆盖四个球的完整 4 秒轮换、201 个相位，以及加载结束后的停止、展开交互、窄屏按钮、原有文字效果和回退模式。
- 减少动态效果时仅显示三个等距静止球。加载期间额外玻璃绘制和文字采样均为零，浏览器异常为空。
