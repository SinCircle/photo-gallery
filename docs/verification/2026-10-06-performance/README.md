# 性能与细节修复

本次以连续转场和推点加载动画已经完成的版本为基线。保留文字颜色、局部软阴影公式、玻璃材质参数及动效轨迹，调整工作调度、图像加载和缓冲区生命周期。

## 改动

- 玻璃改为有变化才唤醒，合并同帧通知；照片仍按屏幕刷新率运动，局部玻璃最多每秒采样 60 次。用 transitionrun/end/cancel 与工具条运动状态跟踪动画，不逐帧扫描 getAnimations。
- 工具条变形期间复用固定尺寸表面，结束后恢复实际尺寸。避免每个中间宽度新建三张 GPU 纹理；非零模糊的缓存也设定数量上限。渐变文字及阴影算法保持原样。
- 背景模糊只缓存工具条附近区域，边缘保留四倍模糊半径；为需要读回的画布从创建时选择可频繁读取的存储。
- 打开照片的共享图像转场先完成，再启动玻璃初始化和清晰图解码，避免这些工作阻塞转场截图与播放。
- 普通浏览使用已有的 1920px 展示图；显示像素需求超过其分辨率时请求原图。替换前先解码，并等待拖动/缩放安静下来。下载继续使用原图。
- 展示图失败自动尝试原图；全部失败时保留缩略图、释放工具条并提供重试。离开页面取消未完成加载与定时器。
- 压缩加载圆点的静止关键帧，保留运动、速度、70ms 错峰和轻微回弹。修复触摸留下悬停状态，以及丢失指针捕获或窗口失焦后拖动状态未释放的问题。

## 本机测量

Chrome 154，AMD Radeon 集成显卡的硬件加速 ANGLE/D3D11，桌面 1440×1000、DPR 1。屏幕约 240Hz；下表的帧间隔来自主文档 requestAnimationFrame，**不是 GPU 呈现帧率或真实手机测试**。性能测试没有与其他浏览器测试并行。

交互每组发送 120 次可信 CDP 输入，目标间隔 1/60 秒；处理阻塞会延长实际输入时间。下表取两次均值。基线来自最后一组交错对照，最终候选在缩小静止表面后单独复测两次。

| 桌面场景 | 基线 | 最终候选 |
| --- | ---: | ---: |
| 120 次滚轮缩放：主线程用时 | 6,588ms | 1,196ms（减少 82%） |
| 同组输入实际完成时间 | 6,694ms | 2,256ms |
| 缩放帧间隔 p95 | 45.9ms | 8.3ms |
| 两组缩放中超过 50ms 的长任务 | 34 | 0 |
| 120 次拖动：主线程用时 | 1,632ms | 1,030ms（减少 37%） |
| 静止一秒的应用动画回调 | 244–245 次 | 0 次 |
| 静止一秒的主线程用时 | 40.3–44.0ms | 0.50–0.60ms |
| 示例照片首次清晰图请求 | 3,150,133 字节 | 168,780 字节（减少 94.6%） |

示例照片为 IMG_20260815_153938.jpg。普通展示读取宽 1920px 的派生图，放大后实际切换为宽 3973px 的原图；这项网络节省不适用于本来就需要原图的放大查看。

导航两轮交错对照中，桌面转场准备时间由 99.7–499.6ms 降至 19.4–26.1ms。实际转场播放期间，候选帧间隔 p95 为 4.3–16.8ms，基线为 24.9–204.6ms。冷图形初始化和运行环境会造成波动，不把单次最优值当成保证。

**边界与代价：**为了让共享照片先顺畅运动，清晰图和工具条随后就绪。桌面从点击到工具条完全展开约 2.79–2.85 秒，基线约 2.23–2.61 秒。390×844、DPR 2、CPU 降速 4 倍的模拟中，转场准备改善为约 166–172ms，但后续玻璃初始化、布局和工具条展开仍有长任务，总主线程用时没有降低。此轮不能声称低性能移动设备已完全无卡顿；没有真机 Safari/HarmonyOS 测试。

## 功能检查

- 加载动画在 1440px/DPR 1、390px/DPR 2、320px/DPR 2 的各 101 个相位中保持排布、间距和回弹；静止背景下动画不触发画布重绘。减少动态效果时保留三个静止圆点。
- 桌面及 390/320px 的工具条控制区域、文字实际阴影像素、WebGL 不可用时的 CSS 回退、退出清理均通过。
- 打开/返回的五个转场相位、首页滚动恢复、浏览器历史、快速反向操作、放大后返回、尺寸变化和转场 API 缺失回退通过。
- 派生图失败、两级图像都失败、重试、放大请求原图、取消动画后重新静止通过。
- 连续 20 次打开/返回后，垃圾回收后的 DOM 节点与事件监听数量恢复为测试前的相同值；无遗留画布、动画和帧回调。
- 从 npm 缓存的原始 LiquidGlass 1.0.3 包重新应用补丁，再应用一次，产物与当前依赖逐字节一致。依赖补丁 SHA256：`769f52704e2cfccdabfbe7d9cc908297ba73d4ec4da2e811c582ada6ca86e41c`。
